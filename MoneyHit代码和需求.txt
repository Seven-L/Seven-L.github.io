                <h2>核心功能需求</h2>
                
                <h3>1. 文案与音轨生成模块</h3>
                <ul>
                    <li>提供两种文案生成方式（可单选、多选或都不选）：
                        <ul>
                            <li>根据产品名称和固定提示词生成</li>
                            <li>根据初始文案和固定提示词生成</li>
                        </ul>
                    </li>
                    <li>两种方式都使用DeepSeek和豆包API，但使用不同的固定提示词</li>
                    <li>允许用户直接输入文案，跳过生成步骤</li>
                    <li><strong>多模型并行调用</strong> DeepSeek、豆包、通义千问等API生成文案</li>
                    <li>文案编辑与整合界面</li>
                    <li>通过网络 API 调用 Windows 电脑上的 CosyVoice 生成音频</li>
                </ul>
                
                <h3>2. 智能视频二创模块</h3>
                <ul>
                    <li>通过抖音链接下载视频素材</li>
                    <li>本地上传素材支持</li>
                    <li>AI 视频分析（人脸检测、语义匹配）</li>
                    <li>可视化时间轴编辑界面</li>
                    <li><strong>去除原素材声音</strong>，使用CosyVoice生成的音频作为最终音轨</li>
                    <li>丰富的视觉效果库（转场、滤镜、贴纸、蒙版）</li>
                    <li>生成多个版本视频作为备选</li>
                    <li><strong>新增动画、特效和音效库</strong>（针对中老年女性群体优化）</li>
                </ul>
                
                <h3>3. 导出模块</h3>
                <ul>
                    <li>导出最终 MP4 视频</li>

                    <li>导出剪映草稿文件 (.draft)</li>
                    <li>优化的去字幕后期处理功能</li>

            <div class="section">
                <h2>技术决策与优化方案</h2>
                
                <div class="decision">
                    <h3>去字幕方案决策</h3>
                    <p>经过对比分析，我们选择 <strong>OpenCV + OCR 方案</strong> 作为主要去字幕方案：</p>
                    <ul>
                        <li><strong>处理动态文本优势</strong>：能够有效处理抖音短视频中动态位置的文本和字幕</li>
                        <li><strong>精准识别</strong>：OCR技术可以准确识别各种字体和位置的文本</li>
                        <li><strong>灵活性高</strong>：可以适应不同视频场景的字幕位置变化</li>
                        <li><strong>保留 video-subtitle-remover 作为备选</strong>：当用户对质量有极高要求时可使用</li>
                    </ul>
                </div>
                
                <div class="decision">
                    <h3>AI视频分析方案决策</h3>
                    <p>经过对比分析，我们选择 <strong>硅基流动/魔搭平台的视频理解大模型</strong> 作为主要分析方案：</p>
                    <ul>
                        <li><strong>语义理解更强</strong>：专门针对视频内容训练，理解更准确</li>
                        <li><strong>情感分析更优</strong>：能更好地捕捉视频中的情感元素</li>
                        <li><strong>场景适配更好</strong>：更适合中文短视频场景</li>
                        <li><strong>集成CLIP作为本地备选</strong>：当网络不稳定时使用本地CLIP模型</li>
                    </ul>
                </div>
                
                <div class="decision">
                    <h3>智能素材管理系统</h3>
                    <p>实现智能素材管理与语义标签系统：</p>
                    <ul>
                        <li><strong>自动标签</strong>：上传素材自动生成语义标签</li>
                        <li><strong>智能搜索</strong>：用自然语言查找素材</li>
                        <li><strong>语义匹配</strong>：根据文案内容推荐合适素材</li>
                        <li><strong>分类管理</strong>：按场景、情感、颜色自动分类</li>
                    </ul>
                </div>
                
                <div class="decision">
                    <h3>智能节奏分析系统</h3>
                    <p>实现智能节奏与剪辑点分析：</p>
                    <ul>
                        <li><strong>文案节奏分析</strong>：分析文案情感强度和重点</li>
                        <li><strong>智能剪辑点</strong>：根据文案重音自动设置剪辑节奏</li>
                        <li><strong>时长优化</strong>：重要内容自动延长显示时间</li>
                        <li><strong>内容匹配</strong>：视频画面与文案内容精准同步</li>
                    </ul>
                </div>

                <h3>M4芯片深度优化</h3>
                <ul>
                    <li>使用为 Apple Silicon 编译的 Python 库</li>
                    <li>FFmpeg 启用 Metal 加速: <code>-hwaccel videotoolbox -vcodec h264_videotoolbox</code></li>
                    <li>多线程处理: 使用 concurrent.futures 实现模型并行调用和视频处理并行化</li>
                    <li>内存优化: 利用 M4 芯片的统一内存架构，减少数据拷贝</li>
                </ul>
