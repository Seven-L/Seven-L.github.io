MoneyHitter 开发指南 2.0

专为中老年女性短视频二创带货优化的智能创作平台

项目概述

开发名为 "MoneyHitter" 的桌面应用程序，集成 AI 文案生成、语音合成和智能视频编辑功能，专门用于短视频二创带货，目标用户为中老年女性群体。

核心要求： 支持多模型并行、丰富的视觉效果库、M4芯片深度优化、本地网络环境优先、智能素材管理和节奏分析。

系统架构

MoneyHitter 系统架构图

[此处应放置系统架构图]

架构说明：前端使用PyQt6实现桌面UI，后端使用Python处理核心逻辑，通过多线程技术并行处理多个大模型调用，利用M4芯片的NPU进行本地模型推理。

技术栈选择

  • 前端框架: PyQt6 - 提供跨平台桌面应用支持
  • 后端语言: Python 3.9+ - 丰富的AI库生态系统
  • 视频处理: OpenCV, MoviePy, VidGear - 专业视频处理库
  • AI模型: PaddleOCR, Transformers, Qwen2-1.5B-Instruct - 本地AI能力
  • 并行处理: Concurrent.Futures, Asyncio - 多模型并行调用
  • 硬件加速: Metal Performance Shaders - M4芯片优化

技术实现方案

去字幕方案

使用 OpenCV + PaddleOCR + VidGear 方案 作为主要去字幕方案，保留video-subtitle-remover作为备选：

方案 中文识别精度 处理速度 资源消耗 M4芯片优化
OpenCV + PaddleOCR + VidGear 优秀 较快 中等 支持GPU加速
video-subtitle-remover 良好 一般 较高 有限支持
  • 中文识别优势：PaddleOCR针对中文优化，准确率较高
  • 处理速度优势：VidGear利用多线程提高处理效率
  • 硬件加速：支持M4芯片GPU加速，提升处理性能

AI视频分析方案

使用 硅基流动/魔搭平台的视频理解大模型 作为主要分析方案，CLIP作为本地备选：

  • 语义理解：专门针对视频内容训练，理解更准确
  • 情感分析：能更好地捕捉视频中的情感元素
  • 场景适配：更适合中文短视频场景
  • 本地备选：当网络不稳定时使用本地CLIP模型

智能素材管理系统

实现智能素材管理与语义标签系统：

  • 自动标签：上传素材自动生成语义标签
  • 智能搜索：用自然语言查找素材
  • 语义匹配：根据文案内容推荐合适素材
  • 分类管理：按场景、情感、颜色自动分类

智能节奏分析系统

实现智能节奏与剪辑点分析：

  • 文案节奏分析：分析文案情感强度和重点
  • 智能剪辑点：根据文案重音自动设置剪辑节奏
  • 时长优化：重要内容自动延长显示时间
  • 内容匹配：视频画面与文案内容精准同步

M4芯片深度优化

  • 使用为Apple Silicon编译的Python库
  • FFmpeg启用Metal加速: -hwaccel videotoolbox -vcodec h264_videotoolbox
  • 多线程处理: 使用concurrent.futures实现模型并行调用和视频处理并行化
  • 内存优化: 利用M4芯片的统一内存架构，减少数据拷贝
  • NPU加速: 使用Core ML和Metal Performance Shaders加速本地模型推理

高级去字幕功能实现

import cv2 import numpy as np from paddleocr import PaddleOCR from vidgear.gears import WriteGear import concurrent.futures class AdvancedSubtitleRemover: def __init__(self, use_gpu=True): self.ocr = PaddleOCR(use_angle_cls=True, lang="ch", use_gpu=use_gpu, show_log=False) self.writer = None def remove_subtitles_advanced(self, input_path, output_path): cap = cv2.VideoCapture(input_path) fps = cap.get(cv2.CAP_PROP_FPS) width = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH)) height = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT)) self.writer = WriteGear(output_path, compression_mode=True, logging=False, **self.get_output_params(fps, width, height)) frame_count = 0 batch_size = 10 while True: frames = [] for _ in range(batch_size): ret, frame = cap.read() if not ret: break frames.append(frame) if not frames: break processed_frames = self.process_frame_batch(frames) for frame in processed_frames: self.writer.write(frame) frame_count += 1 if frame_count % 30 == 0: print(f"已处理 {frame_count} 帧...") cap.release() self.writer.close() return True def process_frame_batch(self, frames): processed_frames = [] for frame in frames: ocr_result = self.ocr.ocr(frame, cls=True) if ocr_result and ocr_result[0]: processed_frame = self.remove_detected_text(frame, ocr_result[0]) processed_frames.append(processed_frame) else: processed_frames.append(frame) return processed_frames def remove_detected_text(self, frame, ocr_results): processed_frame = frame.copy() for result in ocr_results: text_box = result[0] text = result[1][0] confidence = result[1][1] if confidence > 0.3: points = np.array(text_box, dtype=np.int32) x_min, y_min = np.min(points, axis=0) x_max, y_max = np.max(points, axis=0) expand = 5 x_min = max(0, x_min - expand) y_min = max(0, y_min - expand) x_max = min(frame.shape[1], x_max + expand) y_max = min(frame.shape[0], y_max + expand) processed_frame = self.smart_inpaint(processed_frame, x_min, y_min, x_max, y_max) return processed_frame def smart_inpaint(self, frame, x_min, y_min, x_max, y_max): text_region = frame[y_min:y_max, x_min:x_max] if text_region.size == 0: return frame if (y_min > 10 and frame.shape[0] - y_max > 10 and x_min > 10 and frame.shape[1] - x_max > 10): top_region = frame[max(0, y_min-10):y_min, x_min:x_max] bottom_region = frame[y_max:min(frame.shape[0], y_max+10), x_min:x_max] if top_region.size > 0 and bottom_region.size > 0: avg_color = np.concatenate([top_region, bottom_region]).mean(axis=(0, 1)) frame[y_min:y_max, x_min:x_max] = avg_color return frame def get_output_params(self, fps, width, height): return { "-input_framerate": fps, "-vcodec": "h264_videotoolbox", "-preset": "fast", "-crf": 23, "-pix_fmt": "yuv420p", "-vf": f"scale={width}:{height}" }

UI界面设计

设计理念

采用苹果公司软玻璃渐变风格，以Google logo颜色（蓝、绿、黄、红）为渐变主色调，参考MoneyPrinterTurbo的排版布局。

界面布局要求

  • 左侧导航栏：首页、使用说明、模板库、素材库、大模型库
  • 中央工作区：文案及音频生成、视频编辑预览区域
  • 右侧控制面板：效果预设、参数调整、导出选项
  • 底部状态栏：处理进度、系统状态、提示信息

主要界面组件

  • 文案生成区域：产品名称输入、原文案输入、模型选择、提示词输入
  • 音频上传区域：音频文件选择、预览播放、时长显示
  • 视频编辑区域：时间轴、视频预览、效果拖拽区
  • 效果库面板：转场、滤镜、贴纸、蒙版、动画、音效、特效分类展示
  • 导出设置面板：视频格式、分辨率、字幕设置、剪映草稿导出

特别要求

  • 提供直观的图形界面，适合非技术用户操作
  • 支持用户自主配置各大模型平台的API Key
  • 可视化字幕区域选择功能
  • 充分利用M4芯片的性能优势（Metal加速、多线程）
  • 丰富的视觉效果库，针对中老年女性群体优化
  • 最终打包为可在本地运行的应用程序（.app格式）
  • 支持本地网络环境使用，减少对外部网络的依赖
  • 免费部署，除大模型token外不产生额外费用
  • 提供"一键成片"与"深度自定义"双模式工作流

部署与打包

环境要求

  • macOS 13.0+ (Ventura)
  • Mac mini with M4 chip
  • 16GB+ 统一内存
  • Python 3.9+
  • FFmpeg with Metal acceleration
